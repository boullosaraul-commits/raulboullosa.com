# raulboullosa.com

Sitio personal de Raúl Alberto Rivera Boullosa: ensayos, investigación y proyectos sobre economía política, cultura y tecnología.

## Estructura

El sitio es estático y no requiere un proceso de compilación. Los archivos públicos están en `dist/`.

- `dist/index.html`: portada
- `dist/textos/`: archivo de publicaciones
- `dist/investigacion/`: líneas de investigación
- `dist/proyectos/`: proyectos docentes y de datos
- `dist/sobre-mi/`: semblanza
- `dist/assets/site.css`: sistema visual compartido

## Publicación

La carpeta de salida es `dist`. En un servicio de publicación estática, no se necesita comando de compilación.
